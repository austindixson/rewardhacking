Starting point

Bottom line

Key takeaways

Variance spikes are a real leading indicator

On the binary keyword backdoor, within-batch hidden variance rises before the hack consolidates — consistent with Prime’s dynamics paper.

Gradient gating works; behavior suppression does not

Vigilant runs zero hidden_gradient_active at s99. Behavioral hidden_reward can stay > 0. Log both metrics.

Timing is not the win — behavior shaping is

Variance vigilant ≈ control on visible (Δs99 +0.006). Oracle (+0.179) and behavior-penalty (+0.225) dominate; random kill matches vigilant timing.

Mechanism replicates; visible reward does not

Multiseed: P0 visible 0.654±0.24, P3 0.621±0.21 — all complete seeds show hga→0, but visible spans 0.40–0.90.

Not a general hacking detector

Visible-constraint: ~0.98 visible but trigger in 1/5 seeds. Continuous oracle early-kill hurts visible (0.39). Sycophancy: no trigger.

Durable contribution = harness + honest ablations

Open env, oracle/random/penalty baselines, regret curves, and published negative results — not “reward hacking solved.”
